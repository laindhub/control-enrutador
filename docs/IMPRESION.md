El botón de imprimir abre el diálogo nativo de impresión. No imprime de manera desatendida: el usuario debe confirmar. En el diálogo usar A4 vertical, una copia, una página por hoja y una cara, pues la imposición y las dos hojas idénticas ya están integradas en el PDF.

Para actualizar la extensión en el futuro, subir un nuevo ZIP completo, versionar la ruta del descargable, actualizar la vista y agregar los SHA de verificación. No reemplazar el archivo original bajo el mismo nombre para evitar cachés obsoletos.
